## 📌 Featured Projects

**Strata Advisor** *(private repo)* — Quantitative Finance
Evidence-based, tax-aware portfolio management system operating strictly as a Strategic Advisor. Uses a 3-layer meta-allocation framework (Core, Satellite, Tactical) with ML-driven tactical alpha signals and a tax-aware filter that suppresses sales when tax drag exceeds expected alpha. Advisor Mode stages trade intents for explicit user approval rather than auto-executing.

**[San Diego Land Use RAG](https://github.com/AreTaj/sd-land-use-rag)** — NLP · Information Retrieval
Domain-adapted transformer pipeline for intelligent legal document retrieval and generation.

**[Migraine Navigator](https://github.com/AreTaj/Migraine-Navigator)** — Health Tech · ML
Cross-platform desktop app (Tauri/React/FastAPI) that tracks, analyzes, and predicts migraine risk. Runs a personalized Gradient Boosting Hurdle Model locally on-device, with a heuristic engine for new users and automatic ML handoff as data accumulates. Features hourly risk forecasting via a "Truth Propagation" technique, weather-correlated triggers, and background model retraining.

**[EuroSat TensorFlow](https://github.com/AreTaj/eurosat-Tensorflow)** — Computer Vision
Land cover classification from satellite imagery using Convolutional Neural Networks.

**[Option Pricing](https://github.com/AreTaj/option-pricing)** — Computational Finance
Black-Scholes option pricing model with interactive visualization.
